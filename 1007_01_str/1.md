좋아. 아까 버전의 **기능 목록 중심 구조는 그대로 두고**, 각 함수 옆에 “정확히 뭘 하는지 / 인자가 뭔지 / 주의할 점”을 한두 문장씩만 붙이겠다. 첨부한 정리에서 다룬 `std::string` 멤버와 주변 문자열 기능을 기준으로 한다. 붙여넣은 텍스트(1)

# 1. `char` 자체

```cpp
char c = 'A';

c == 'A';
c < 'Z';

int x = c;        // 문자 코드를 정수로
char d = x;       // 정수를 char로
```

`char`는 문자이면서 정수형이므로 비교와 산술 연산이 가능하다.

숫자 한 자리 변환은 특히 자주 쓴다.

```cpp
int x = '7' - '0';    // 7
char c = '0' + 7;     // '7'
```

---

# 2. `<cctype>` — 문자 분류

```cpp
isdigit(c);    // 0~9
isalpha(c);    // 알파벳
isalnum(c);    // 알파벳 또는 숫자

islower(c);    // 소문자
isupper(c);    // 대문자

isspace(c);    // 공백류: ' ', '\n', '\t', ...

ispunct(c);    // 구두점
isxdigit(c);   // 16진수 문자

iscntrl(c);    // 제어 문자
isprint(c);    // 화면에 출력 가능한 문자
isgraph(c);    // 출력 가능하면서 공백은 아닌 문자
```

판별 함수는 `bool`이 아니라 `int`를 반환한다.

```cpp
0        // false
nonzero  // true
```

따라서:

```cpp
if (isalpha(c)) {
    ...
}
```

라고 쓰고,

```cpp
if (isalpha(c) == 1)   // X
```

처럼 쓰지 않는다.

대소문자 변환:

```cpp
tolower(c);
toupper(c);
```

보통 안전하게:

```cpp
if (isalpha((unsigned char)c)) {
    ...
}

c = tolower((unsigned char)c);
```

# 3. `string` 생성

가장 기본:

```cpp
string a;

string b = "hello";
string c("hello");
```

같은 문자 반복:

```cpp
string s(5, 'x');

// "xxxxx"
```

복사:

```cpp
string a = "hello";
string b = a;
```

`b`는 별도의 `string` 객체다.

다른 `string`의 일부:

```cpp
string a = "abcdef";

string b(a, 2);       // index 2부터 끝까지: "cdef"
string c(a, 2, 3);    // index 2부터 3글자: "cde"
```

C 문자열에서:

```cpp
char buf[] = "abcdef";

string a(buf);        // '\0'까지
string b(buf, 3);     // 정확히 앞 3글자: "abc"
```

iterator 구간:

```cpp
string s(v.begin(), v.end());
```

즉 문자 range가 있으면 그 range로 문자열을 만들 수 있다.

```cpp
vector<char> v = {'a', 'b', 'c'};

string s(v.begin(), v.end());

// "abc"
```

initializer list:

```cpp
string s({'a', 'b', 'c'});
```

C++23 range 생성:

```cpp
string s(from_range, range);
```

# 4. 대입

```cpp
string s;

s = "hello";
s = other;
s = 'A';
s = {'a', 'b', 'c'};
```

기존 문자열 내용을 통째로 교체한다.

move도 지원한다.

```cpp
s = move(other);
```

일반 코테에서는 직접 `move`할 일은 많지 않다.

# 5. 길이와 상태

```cpp
s.size();
s.length();
```

둘 다 현재 문자 개수를 반환한다.

```cpp
s.empty();
```

비어 있으면 `true`.

```cpp
if (s.empty()) {
    ...
}
```

```cpp
s.max_size();
```

이론적으로 이 구현에서 가질 수 있는 최대 문자열 크기. 코테에서는 거의 안 쓴다.

# 6. 메모리 용량

```cpp
s.capacity();
```

현재 재할당 없이 저장할 수 있는 문자 수.

```cpp
s.reserve(1000);
```

최소 1000글자 정도를 담을 공간을 미리 확보한다.

문자열을 계속 `push_back`할 것을 알고 있을 때 재할당을 줄일 수 있다.

```cpp
string result;
result.reserve(n);
```

```cpp
s.shrink_to_fit();
```

남는 capacity를 줄여 달라고 요청한다. 꼭 줄어든다는 강한 보장은 없다.

# 7. `resize`

```cpp
s.resize(5);
```

문자열 길이를 5로 만든다.

현재보다 길면 새 문자가 추가되고, 짧으면 뒤가 잘린다.

문자 지정:

```cpp
string s = "abc";

s.resize(5, 'x');

// "abcxx"
```

축소:

```cpp
s.resize(2);

// "ab"
```

C++23에는:

```cpp
s.resize_and_overwrite(...);
```

도 있지만 코테에서는 거의 필요 없다.

```cpp
s.clear();
```

```cpp
s.empty();   // true
```

# 9. 문자 접근

```cpp
s[i];
```

가장 흔하게 사용한다.

```cpp
char c = s[3];

s[3] = 'x';
```

범위 검사를 하지 않는다.

반면:

```cpp
s.at(i);
```

는 범위를 검사한다.

잘못된 위치라면 예외가 발생할 수 있다.

코테에서는 보통:

```cpp
s[i]
```

를 쓴다.

첫 문자:

```cpp
s.front();
```

마지막 문자:

```cpp
s.back();
```

둘 다 수정도 가능하다.

```cpp
s.front() = 'A';
s.back() = 'Z';
```

단 빈 문자열에서 `front()`나 `back()`을 호출하면 안 된다.

# 10. iterator

앞 방향:

```cpp
s.begin();
s.end();
```

const iterator:

```cpp
s.cbegin();
s.cend();
```

역방향:

```cpp
s.rbegin();
s.rend();
```

const 역방향:

```cpp
s.crbegin();
s.crend();
```

그래서 일반 STL 알고리즘을 그대로 사용할 수 있다.

```cpp
sort(s.begin(), s.end());

reverse(s.begin(), s.end());
```

직접 순회:

```cpp
for (auto it = s.begin(); it != s.end(); ++it) {
    cout << *it;
}
```

보통은 더 간단하게:

```cpp
for (char c : s) {
    ...
}
```

실제 문자를 수정하려면:

```cpp
for (char& c : s) {
    ...
}
```

# 11. 뒤에 붙이기

문자열:

```cpp
s += "abc";
s += other;
```

문자 하나:

```cpp
s += 'x';
```

문자 하나를 붙인다는 의도를 더 직접 나타내려면:

```cpp
s.push_back('x');
```

예:

```cpp
string result;

for (char c : s) {
    if (isdigit(c)) {
        result.push_back(c);
    }
}
```

# 12. `append`

`+=`의 좀 더 일반적인 형태다.

```cpp
s.append(other);
s.append("hello");
```

다른 문자열 일부:

```cpp
s.append(other, pos, count);
```

`other[pos]`부터 `count`글자를 뒤에 붙인다.

C 문자열의 앞 `count`글자:

```cpp
s.append(buf, count);
```

같은 문자 반복:

```cpp
s.append(5, 'x');

// "xxxxx"를 추가
```

iterator range:

```cpp
s.append(first, last);
```

C++23:

```cpp
s.append_range(range);
```

실전에서는 보통:

```cpp
s += other;
s.push_back(c);
```

정도로 충분하다.

# 13. `pop_back`

```cpp
s.pop_back();
```

마지막 문자 하나를 제거한다.

```cpp
string s = "abcd";

s.pop_back();

// "abc"
```

빈 문자열에서는 호출하지 않는다.

# 14. `assign`

문자열 내용을 새 내용으로 바꾼다.

```cpp
s.assign(other);

s.assign("hello");

s.assign(5, 'x');   // "xxxxx"
```

부분 복사:

```cpp
s.assign(other, pos, count);
```

C buffer:

```cpp
s.assign(buf, count);
```

iterator 구간:

```cpp
s.assign(first, last);
```

C++23:

```cpp
s.assign_range(range);
```

대부분의 경우 그냥:

```cpp
s = other;
```

가 더 읽기 쉽다.

# 15. `insert`

문자열 중간에 내용을 끼워 넣는다.

```cpp
string s = "abef";

s.insert(2, "cd");

// "abcdef"
```

기본적으로:

```cpp
s.insert(pos, other);
```

다른 문자열 일부만:

```cpp
s.insert(
    pos,
    other,
    other_pos,
    count
);
```

문자를 여러 번:

```cpp
s.insert(pos, 5, 'x');
```

iterator 위치도 가능:

```cpp
s.insert(
    s.begin() + 2,
    'x'
);
```

여러 문자:

```cpp
s.insert(
    s.begin() + 2,
    5,
    'x'
);
```

iterator range:

```cpp
s.insert(
    s.begin() + 2,
    first,
    last
);
```

C++23:

```cpp
s.insert_range(iterator, range);
```

중간 삽입은 뒤쪽 문자들을 움직여야 해서 일반적으로 \(O(n)\)이다.

# 16. `erase`

문자열 일부를 지운다.

가장 중요한 형태:

```cpp
s.erase(pos, count);
```

예:

```cpp
string s = "abcdef";

s.erase(2, 3);

// "abf"
```

즉:

```text
index 2부터 3글자 삭제
```

`pos`부터 끝까지:

```cpp
s.erase(pos);
```

문자 하나:

```cpp
s.erase(s.begin() + i);
```

iterator 구간:

```cpp
s.erase(
    s.begin() + l,
    s.begin() + r
);
```

삭제 범위는:

```text
[l, r)
```

이다.

# 17. `replace`

일부를 제거하면서 동시에 다른 문자열을 넣는다.

```cpp
s.replace(pos, count, "new");
```

예:

```cpp
string s = "I like cats";

s.replace(7, 4, "dogs");

// "I like dogs"
```

즉:

```text
pos부터 count글자를 제거하고
그 자리에 새 내용을 삽입
```

다른 문자열:

```cpp
s.replace(pos, count, other);
```

다른 문자열 일부:

```cpp
s.replace(
    pos,
    count,
    other,
    other_pos,
    other_count
);
```

같은 문자 반복으로 교체:

```cpp
s.replace(pos, count, 5, 'x');
```

iterator 범위도 된다.

```cpp
s.replace(first, last, other);
```

C++23:

```cpp
s.replace_with_range(first, last, range);
```

# 18. `swap`

두 문자열의 내용을 교환한다.

```cpp
a.swap(b);
```

또는:

```cpp
swap(a, b);
```

보통 전체 문자열을 문자 하나씩 복사하는 식으로 처리하지 않고 내부 상태를 효율적으로 교환한다.

# 19. `substr`

부분 문자열을 **새로운 `string`으로 만들어 반환**한다.

```cpp
s.substr(pos, count);
```

예:

```cpp
string s = "abcdefgh";

string t = s.substr(2, 3);

// "cde"
```

중요한 점:

```cpp
substr(2, 3)
```

의 `3`은 끝 index가 아니라 **길이**다.

즉:

```text
[2, 2 + 3)
```

끝까지:

```cpp
s.substr(2);
```

결과:

```text
"cdefgh"
```

`substr`는 새 문자열을 복사하므로 결과 길이가 \(k\)라면 대략 \(O(k)\).

---

# 20. `find`

문자열 검색의 기본.

```cpp
auto pos = s.find("abc");
```

찾은 부분 문자열의 **시작 index**를 반환한다.

문자 하나:

```cpp
auto pos = s.find('a');
```

`string`도 가능:

```cpp
auto pos = s.find(target);
```

특정 위치부터:

```cpp
auto pos = s.find("abc", start);
```

즉:

```text
index start 이상에서 처음 등장하는 "abc"
```

를 찾는다.

못 찾으면:

```cpp
string::npos
```

따라서 기본 패턴은:

```cpp
auto pos = s.find(target);

if (pos != string::npos) {
    ...
}
```

---

# 21. `rfind`

`find`와 비슷하지만 **뒤쪽 occurrence**를 찾는다.

```cpp
string s = "abc---abc";

s.find("abc");    // 0
s.rfind("abc");   // 6
```

문자도:

```cpp
s.rfind('a');
```

위치 제한도 가능하다.

```cpp
s.rfind("abc", pos);
```

---

# 22. `find_first_of`

이 함수는 **부분 문자열 검색이 아니다.**

```cpp
string s = "hello123";

auto p =
    s.find_first_of(
        "0123456789"
    );
```

뜻:

> `"0123456789"`에 포함된 문자 중 무엇이든 처음 나타나는 위치

결과:

```cpp
p == 5
```

즉 문자 집합 검색이다.

---

# 23. `find_last_of`

같은 문자 집합 검색을 뒤에서 한다.

```cpp
string path =
    "/home/test/a.txt";

auto p =
    path.find_last_of('/');
```

마지막 `/`의 위치를 얻는다.

파일 경로, 확장자 등에서 꽤 유용하다.

---

# 24. `find_first_not_of`

주어진 문자 집합에 **속하지 않는 첫 문자**를 찾는다.

```cpp
string s = "   hello";

auto p =
    s.find_first_not_of(' ');

// 3
```

앞쪽 공백 제거 등에 쓸 수 있다.

```cpp
s.find_first_not_of(" \t\n\r");
```

---

# 25. `find_last_not_of`

뒤에서부터 주어진 문자 집합에 속하지 않는 첫 위치.

```cpp
string s = "hello   ";

auto p =
    s.find_last_not_of(' ');
```

뒤쪽 공백 제거 등에 쓴다.

---

# 26. 검색 함수 6종

결국 검색 계열은 이 여섯 개다.

```cpp
s.find(...);
s.rfind(...);

s.find_first_of(...);
s.find_last_of(...);

s.find_first_not_of(...);
s.find_last_not_of(...);
```

`find/rfind`는 **문자열 자체 검색**, `*_of`는 **문자 집합 검색**이라고 구분하면 된다. 붙여넣은 텍스트(1)

# 27. `string::npos`

검색 실패값.

```cpp
auto pos = s.find("abc");

if (pos == string::npos) {
    // 없음
}
```

`npos`는 일반적인 `-1`이라는 의미로 생각할 수는 있지만 실제 타입은:

```cpp
string::size_type
```

이다.

그래서:

```cpp
auto pos = s.find(...);
```

가 편하다.

# 28. 문자열 비교 연산자

`string`끼리는 바로 비교된다.

```cpp
a == b;
a != b;

a < b;
a > b;

a <= b;
a >= b;
```

순서는 사전식이다.

```cpp
"abc" < "abd"    // true
"apple" < "cat"  // true
```

그래서:

```cpp
vector<string> v;

sort(v.begin(), v.end());
```

만 해도 문자열이 사전순으로 정렬된다.

# 29. `compare`

비교 결과를 숫자로 받고 싶을 때.

```cpp
int x = a.compare(b);
```

의미:

```text
x < 0    a < b
x == 0   a == b
x > 0    a > b
```

부분 문자열만 비교할 수도 있다.

```cpp
a.compare(
    pos,
    count,
    b
);
```

양쪽 일부:

```cpp
a.compare(
    pos1,
    count1,
    b,
    pos2,
    count2
);
```

대부분의 단순 비교는 그냥:

```cpp
a == b
a < b
```

가 더 편하다.

```cpp
s.starts_with('a');
```

C++23:

```cpp
s.contains("abc");
```

# 31. `copy`

`string`의 일부를 **C buffer로 복사**한다.

```cpp
char buf[100];

size_t n =
    s.copy(
        buf,
        5,
        2
    );
```

뜻:

```text
s[2]부터 최대 5글자 복사
```

중요:

```cpp
s.copy(...)
```

는 마지막의 C 문자열 terminator:

```cpp
'\0'
```

를 자동으로 추가하지 않는다.

따라서 C 문자열로 쓸 거라면:

```cpp
buf[n] = '\0';
```

를 직접 해준다.

# 32. `c_str()`

`std::string`을 C 문자열을 요구하는 함수에 넘기는 가장 중요한 다리다.

```cpp
string s = "hello";

const char* p =
    s.c_str();
```

대표적으로:

```cpp
printf(
    "%s\n",
    s.c_str()
);
```

`printf("%s")`는 `std::string`을 모르고 `const char*`를 원하기 때문이다.

# 33. `data()`

문자열의 연속된 내부 저장소에 대한 포인터.

```cpp
s.data();
```

읽기:

```cpp
const char* p =
    s.data();
```

C++17 이후 수정 가능한 `string`에서는:

```cpp
char* p =
    s.data();
```

도 가능하다.

`c_str()`은 **C 문자열로 읽기 위해 사용한다**는 의도가 강하고,

`data()`는 **실제 연속 저장소에 접근한다**는 의미가 강하다.

# 34. `c_str()` / `data()` 포인터의 수명

이런 코드는 주의한다.

```cpp
string s = "hello";

const char* p =
    s.c_str();

s += " very long string";
```

문자열 수정으로 재할당이 일어나면 기존 `p`가 더 이상 유효하지 않을 수 있다.

따라서 C 함수에 넘길 때는 보통:

```cpp
printf("%s", s.c_str());
```

처럼 바로 사용하는 것이 편하다.

# 61. `printf` 문자열 formatting

기본:

```cpp
printf("%s", str);
```

폭 10:

```cpp
printf("%10s", str);
```

오른쪽 정렬된다.

왼쪽 정렬:

```cpp
printf("%-10s", str);
```

최대 5글자:

```cpp
printf("%.5s", str);
```

```cpp
printf(
    "%.*s",
    len,
    str
);
```

# 62. `scanf("%s")`

`std::string`에 직접 넣을 수 없다.

```cpp
string s;

// scanf("%s", &s);   // X
```

C buffer를 거친다.

```cpp
char buf[100];

scanf(
    "%99s",
    buf
);

string s = buf;
```

`%99s`의 `99`는 overflow 방지를 위한 최대 문자 수다.

`%s` 역시 whitespace에서 멈춘다.

# 63. `scanf("%c")`

문자 하나:

```cpp
char c;

scanf("%c", &c);
```

이 경우 개행이나 공백도 읽는다.

앞 whitespace를 무시하고 다음 non-whitespace 문자를 읽고 싶다면:

```cpp
scanf(" %c", &c);
```

format string의 앞 공백이 중요하다.

# 64. `scanf` scanset

```cpp
);
```

영소문자가 계속되는 동안 읽는다.

반대로:

```cpp
scanf(

    buf
);
```

는 개행이 아닌 문자를 읽는다.

즉 한 줄 입력 비슷하게 쓸 수 있다.

일반 `cin >> s`와 같은 방식으로 whitespace 기준 tokenization한다.

# 87. `string_view`

C++17.

```cpp
string_view v;
```

기존 문자열을 **복사하지 않고 바라보는 객체**다.

```cpp
string s =
    "hello world";

string_view v = s;
```

대략 내부적으로:

```text
pointer + length
```

정도를 가진다고 생각하면 된다.

# 88. `string_view` 기능

`string`과 상당히 비슷하다.

```cpp
v.size();
v.empty();

v[i];

v.front();
v.back();

v.begin();
v.end();

v.substr(...);

v.find(...);
v.rfind(...);

v.find_first_of(...);
v.find_last_of(...);

v.find_first_not_of(...);
v.find_last_not_of(...);

v.compare(...);

v.starts_with(...);   // C++20
v.ends_with(...);     // C++20
v.contains(...);      // C++23

v.data();
```

하지만 문자열을 소유하지 않으므로 수정용 API:

```cpp
push_back
insert
erase
replace
```

같은 것은 없다.

# 89. `remove_prefix`, `remove_suffix`

`string_view`에서 특히 유용하다.

```cpp
v.remove_prefix(3);
```

앞 3글자를 view에서 제외.

```cpp
v.remove_suffix(2);
```

뒤 2글자를 제외.

실제 문자열을 지우는 게 아니라 **바라보는 범위만 바꾼다.**

그래서 \(O(1)\)이다.

# 90. `string_view` → `string`

소유하는 문자열이 필요하다면:

```cpp

```

이 시점에는 실제 문자들이 복사된다.

# 91. `string_view`와 `printf`

다음은 일반적으로 안전하지 않다.

```cpp
printf(
    "%s",
    v.data()
);
```

`string_view`의 끝에 `'\0'`이 있다는 보장이 없기 때문이다.

길이를 같이 준다.

```cpp
printf(
    "%.*s",
    (int)v.size(),
    v.data()
);
```

# 94. 직접 제공되지 않는 기능들

의외로 다음은 `std::string` 멤버 함수로 없다.

```cpp
s.split(...)
s.trim(...)
s.join(...)
s.replace_all(...)
```

따라서 조합해서 만든다.

split:

```cpp
getline(ss, token, delim)
```

trim:

```cpp
find_first_not_of
find_last_not_of
```

replace all:

```cpp
find + replace
```

join:

```cpp
+=
```

를 반복.

# 95. trim 만들기

왼쪽:

```cpp
auto p =
    s.find_first_not_of(
        " \t\n\r"
    );

if (p == string::npos) {
    s.clear();
}
else {
    s.erase(0, p);
}
```

오른쪽:

```cpp
auto p =
    s.find_last_not_of(
        " \t\n\r"
    );

if (p == string::npos) {
    s.clear();
}
else {
    s.erase(p + 1);
}
```

# 96. replace all 만들기

```cpp
size_t pos = 0;

while (
    (
        pos =
            s.find(
                old_str,

            )
    )
    != string::npos
```

# 97. 모든 occurrence 찾기

```cpp

    (
        pos =
            s.find(
                target,
                pos
            )
    )
    != string::npos
) {

    cout << pos << '\n';

    pos += target.size();
}
```

겹침까지 허용:

```cpp
pos++;
```

에 존재한다.

=============================

vector에는 두 개의 층이 있다. 

1. vector 객체 자체
2. vector 소유의 원소 저장공간 

=============================

원소들은 메모리상 연속되어 있다. 

vector<int> a = {10, 20, 30}; 

int *p = a.data(); 

f(a.data(), a.size()); 

=============================

vector<int> a = {1,2,3}; 
vector<int> b = a; 

새로운 vector가 만들어진다. 

b[0] = 100; 

but 

a[0] == 1;
b[0] == 100; 

=============================

vector<int> &b = a; 

b는 a의 다른 이름 (alias) 이다

b[0] = 100; 

then

a[0] == 100; 

=============================

void f(vector<int> v);

f(a); 

a를 이용해서 새로운 v가 만들어진다. 

Caller : a -> [1,2,3]

Callee : v -> [1,2,3]

v를 수정해도 a에는 영향을 주지 않는다. 

=============================

void f(vector<int>& v); 

v는 원본의 alias이다. 

v[0] = 100; 

하면 Caller의 vector도 바뀐다. 

=============================

void f(const vector<int> & v)

const reference

보통 큰 입력을 받는데 쓴다. 

=============================
